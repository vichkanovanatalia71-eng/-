# 09. Аудит конструкції: самоперевірка, незалежний аудит, виправлення

Ревізія **v2.4** = v2.3 + вимога замовника «цільова маса 700–900 г» + виправлення за незалежним аудитом.
Повний текст аудиту — `reports/independent_audit.md`. Аудит виконував окремий агент, який не бачив міркувань
проєктувальника. Він перевіряв моделі, оснащення й креслення з власними розрахунками. Аудит виконувався, коли пакет
переходив з v2.3 на v2.4, тому частина знахідок стосується обох версій.

**Рекомендації аудитора, які не прийнято:**
* **Центрувати виїмку по осі кришки (x = −15).** Виїмка лишається по центру фронту під логотипом (дизайн v2.2). Тяга
  зміщена на 15 мм від осі. Губчасте ущільнення і зазор 0.9 мм допускають такий перекіс, тест Т6. Якщо Т6 покаже
  проблему, виїмку й логотип можна разом зсунути на вісь кришки (2 параметри).
* **Прибрати полегшувальну порожнину.** Див. M3: вона потрібна для цільової маси.

## 4. Чесні обмеження пакета

* Сила тертя ущільнення, місткість і міцність — **розрахункові оцінки** з позначеними припущеннями, не вимірювання.
* FEA, ударні та термоциклічні випробування не виконувались.
* Ролі CMF-дизайнера, технолога бетону та кост-інженера виконано в основному потоці, без окремих агентів.
