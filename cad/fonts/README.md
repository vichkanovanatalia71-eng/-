# Шрифти

| Файл | Призначення | Ліцензія |
|---|---|---|
| `Montserrat_700Bold.ttf` | Напис STICKBOX на фронті корпусу (v2.6). Ближчий до фірмового вордмарку замовника геометричний гротеск. Контури гліфів перетворюються на полігони в `stickbox/brand.py` | SIL Open Font License 1.1 — `OFL-Montserrat.txt` (© The Montserrat Project Authors) |

OFL дозволяє використовувати шрифт у виробах і логотипах; файл шрифту поширюється разом із текстом ліцензії.
Якщо у замовника є оригінальний векторний файл логотипа (SVG/AI/PDF), ним слід замінити `stickbox/data/brand_mark.json`
і контури напису — геометрія будується з полігонів, тож заміна не потребує змін коду.
