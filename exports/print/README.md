# Файли для друку прототипу (SLA / FDM) — ревізія v3.7

Лише **корпус і кришка**, поруч на столі (без девайса, шнура, повстяної підкладки, масок фарби й NFC-мітки):

| Файл | Що всередині |
|---|---|
| `STICKBOX_01_v3.7_body_lid.3mf` | 2 окремі об'єкти: `STICKBOX_body`, `STICKBOX_lid` (мм, Z угору) — **основний для слайсера** |
| `STICKBOX_01_v3.7_body_lid.stl` | Те саме однією сіткою (2 оболонки) |
| `STICKBOX_01_v3.7_body_lid.step` | Те саме у STEP (точна геометрія) |

* Корпус 120 × 90 × 95 мм (328 мл матеріалу), кришка 108.2 × 82.8 × 14 мм (53.5 мл).
* Розміри — номінальні розміри виробу (без масштабу ×1.002 для форм).
* Заглиблення напису STICKBOX і знака NFC — частина корпусу (1.0 мм), фарбуються після друку.
* Файли збірки (`exports/step/00_…_assembly.step`, `exports/glb/…assembly.glb`) містять усі деталі разом із
  девайсом і шнуром — для друку їх не брати.

Згенеровано: `cd cad && python make_print_file.py`.
